# 이미지메이커 (ImageMaker) — 핸드드로잉 프리미티브 + 스케치 스컬프트 3D 생성기

- 상태: **DRAFT / v1 초안**
- 작성일: 2026-07-25
- 작성자: Architect (시안)
- 프로젝트 명칭: 이미지메이커 (가칭, 영문 ImageMaker)
- 목적: 손으로 그린 2D 스트로크를 기하학적 프리미티브 3D 객체로 생성하고,
  스케치한 프로파일을 표면에 투영해 조각(sculpt)하듯 형태를 완성하는 도구.
  최종 결과물은 게임엔진(Unity/Godot) 호환 glTF 2.0 메시.

---

## 0. 개요

### 0.1 핵심 차별점 (기존 스컬프트와의 차이)
- **기존 (ZBrush/Blender)**: 붓을 대고 마우스로 직접 밀기/당기기 (벡터 방향으로 힘 가함)
- **SketchSculpt**: 변형하고자 하는 위치에 **선을 그린다** → 그 선의 형태(곡률/두께)가
  변형의 프로파일이 됨. 선을 표면에 투영(projection)해 법선 방향으로 디스플레이스먼트 적용.

### 0.2 워크플로우 (마스터 구상 반영)
1. 화면에 원을 그리면 → 구(Sphere) 생성
2. 사각형을 그리면 → 육면체(Box) 생성
3. 객체를 X/Y/Z축으로 회전시켜 작업면을 정면에 둠
4. 그 면에 코 모양의 곡선을 스케치 → 표면이 그 프로파일대로 돌출
5. 각도를 바꿔 옆면/아래도 반복 스케치 → 점점 형태 완성
6. glTF로 내보내 게임엔진 임포트

### 0.3 범위
- MVP: 단일 객체, 프리미티브 생성 + 스케치 스컬프트 + 회전 뷰어
- 확장: 다중 객체, 브러시 종류, 언랩/노말맵 베이크

## 2. 데이터 모델

### 2.1 Stroke (2D 입력)
```
struct Stroke {
  vector<vec2> points;     // 화면 좌표 (정규화 or 픽셀)
  float thickness;         // 선 두께 (펜 압력 or UI)
  int brush_type;          // 0=add, 1=subtract (추가/제거)
};
```

### 2.2 PrimitiveType (생성 대상)
```
enum class PrimitiveType {
  SPHERE,    // 원(닫힌 곡선)
  BOX,       // 사각형
  CYLINDER,  // 직선 + 반경
  CONE,      // 삼각형
  TUBE,      // 자유곡선 (두께 있는)
  ELLIPSOID, // 타원
};
```

### 2.3 Mesh (3D 객체)
```
struct Mesh {
  vector<vec3> vertices;
  vector<vec3> normals;
  vector<uint32_t> indices;
  // sculpt용 추가
  vector<vec3> base_vertices;  // 원본 (undo용)
  vector<vec2> uv;              // Phase 5
};
```

### 2.4 SculptStroke (표면 투영 결과)
```
struct SculptStroke {
  vector<vec3> surface_points;  // 스트로크가 닿은 표면 좌표
  vector<float> displacement;   // 각 점의 변위량 (프로파일에서 추출)
  int axis_lock;                // 작업 시 객체 회전 상태 (undo용)
};
```

## 3. 파이프라인 단계

### Phase 1: 프리미티브 스케치 생성
- 입력: 화면에 그린 스트로크
- 처리:
  1. 스트로크 전처리 (노이즈 제거, 재표본화)
  2. 형태 분류:
     - 닫힌 곡선 + 면적/둘레 비율 → SPHERE 또는 ELLIPSOID
     - 4꼭지점 근사 → BOX
     - 직선 → CYLINDER
     - 3꼭지점 → CONE
  3. 파라미터 추출: 경계박스 너비/높이 → 지름/길이
  4. 메시 생성: ICO sphere / Box / Cylinder geometry
- 출력: Mesh (화면 중앙 배치)

### Phase 2: 다축 회전/이동 뷰어 (컨트롤 명세 v3)

#### 기본 입력
1. **왼쪽 버튼 드래그** → 선 그리기 (스트로크, M3 스케치용)
2. **왼쪽 더블클릭** → 해당 위치 객체 선택 (레이 피킹)
3. **오른쪽 버튼 클릭** → 해당 위치 선 삭제

#### 축 선택 (토글)
- `X` / `Y` / `Z` → 축 선택 (토글, 하나만 활성, 기본 none)

#### 동작 선택 (토글)
- `R` → 회전
- `M` → 이동
- `S` → 화면 회전 (카메라 orbit, 축 무관)
- `T` → 줌 (카메라 dolly, 축 무관, Z 대신 T 사용)

#### 조작 장치
- 선택된 축 + 선택된 동작 상태에서 **마우스 스크롤 / `+` / `−`** → 적용
- 예: X축+R동작+스크롤 → X축 회전
- 예: T동작+스크롤 → 줌

#### UI 표시 (필수)
- 현재 선택된 **축** (X / Y / Z / none)
- 현재 선택된 **동작** (R회전 / M이동 / S화면회전 / T줌)
- 선택된 **객체** 하이라이트

#### 구현
- 쿼터니언 기반 누적 회전/이동 (model matrix)
- 토글 상태 추적: axis_state (X/Y/Z/none), action_state (R/M/S/T/none)
- 객체 피킹: 더블클릭 → 레이-메시 교차
- 실시간 Vulkan 렌더 갱신 (60fps)
- 그리드 + 축 표시 (선택축 하이라이트)

#### 요구사항
- REQ-SS-005 (X/Y/Z 자유 회전/이동)

### Phase 3: 스케치 스컬프트 (핵심)
- 입력: 회전된 객체 정면에 그린 스트로크
- 처리:
  1. 카메라 레이 생성 (스트로크 각 점 → 월드 레이)
  2. 레이-메시 교차 → 표면 점 획득
  3. 스트로크 곡률/두께 → 변위 프로파일 추출
  4. 표면 점 근방 버텍스들을 법선 방향으로 디스플레이스
  5. brush_type=subtract면 반대 방향
- 실시간 반영 (Vulkan 버텍스 버퍼 업데이트)
- undo: base_vertices 복원

### Phase 4: 브러시/보정 (확장)
- 브러시 종류: add / subtract / smooth
- 폴리곤 subdiv (디테일 증가)
- undo/redo 스택
- 대칭 모드 (좌우 대칭 스케치)

### Phase 5: 게임용 후처리 + 출력
- 메시 리듀스 (디테일 유지, 폴리 감소)
- UV 언랩 (단순 cubic 또는 angle-based)
- 노말맵 베이크 (high-poly → low-poly)
- glTF 2.0 export (tinygltf)

### Phase 6: 자유곡선 → 3D 메시 생성 (Stroke-to-Mesh)
- 입력: 화면에 그린 자유곡선 스트로크 (마우스 왼쪽 드래그)
- 처리:
  1. 스트로크를 3D 공간으로 투영 (카메라 레이 → 월드 포인트 시퀀스)
  2. 곡선을 따라 튜브/로프 형태의 메시 생성 (Tube/Extrude)
  3. 반경(radius): 스트로크 두께 또는 고정값 기준
  4. 폐곡선(closed)이면 캡(cap) 처리하여 솔리드化
- 출력: 독립된 3D 메시 객체 (씬에 추가)
- 키 매핑: 예: 스트로크 모드 전용 토글 (시엘 제안받음)
- 검증: 생성된 튜브 메시가 유효한 지오메트리 (non-degenerate, closed if source closed)

#### 요구사항
- REQ-SS-006 (자유곡선 → 3D 메시 변환)

## 4. 요구사항 (Normative, 초안)

**REQ-SS-001** 스트로크 입력은 실시간(60fps)으로 처리되어야 한다.
**REQ-SS-002** 원형 닫힌 곡선은 SPHERE로, 사각형은 BOX로 1:1 매핑되어야 한다.
**REQ-SS-003** 생성된 메시는 법선이 정확히 계산되어야 한다 (라이팅 정상).
**REQ-SS-004** 스케치 스컬프트는 그린 선의 프로파일을 표면에 투영해 변형해야 한다
  (기존 drag 방식이 아닌 projection 방식).
**REQ-SS-005** 객체는 X/Y/Z축으로 자유 회전 가능해야 한다.
**REQ-SS-006** undo는 최소 20단계까지 지원해야 한다.
**REQ-SS-007** 최종 출력은 glTF 2.0이어야 한다 (Unity/Godot 호환).
**REQ-SS-008** 모든 연산은 CPU 또는 GPU(Vulkan)에서 실시간(변형 < 16ms)이어야 한다.

## 7. 결정 사항 (마스터 승인)

1. **입력 장치**: 마우스 + 타블릿 펜. 펜 압력 → `Stroke.thickness` 반영.
2. **두께 결정**: 비례 고정값 기준 (경계박스 너비의 10% → 돌출량). UI 슬라이더로 수정 가능.
3. **지원 프리미티브**: 구/상자/원기둥/콘/튜브/타원 6종 (Architect 기본안 채택, 추후 확장).
4. **폴리곤 시작 해상도**: ICO sphere subdiv 3단계 (약 1.2k 버텍스) (Architect 기본안 채택, 추후 조정).
5. **프로젝트 이름**: 이미지메이커 (가칭, ImageMaker).
