## M2 컨트롤 명세 v3 (최종)

### 기본 입력
1. **왼쪽 드래그** → 선 그리기 (스트로크)
2. **왼쪽 더블클릭** → 객체 선택 (레이-메시 교차)
3. **오른쪽 클릭** → 선 삭제

### 축 선택 (토글)
- `X` / `Y` / `Z` → 축 선택 (하나만 활성, 기본 none)

### 동작 선택 (토글)
- `R` → 회전
- `M` → 이동
- `S` → 화면 회전 (orbit)
- `T` → 줌 (Z 대신 T, Z는 순수 축)

### 조작
- 선택된 축 + 선택된 동작 + **스크롤 / `+` / `−`** → 적용
- 예: X+R+스크롤 → X축 회전
- 예: T+스크롤 → 줌

### UI 표시 (필수)
- 선택 **축** (X/Y/Z/none)
- 선택 **동작** (R/M/S/T)
- 선택 **객체** 하이라이트

### 구현
- 쿼터니언 누적 회전/이동
- 토글 상태: axis_state (X/Y/Z/none), action_state (R/M/S/T/none)
- 객체 피킹: 더블클릭 → 레이-메시
- 실시간 Vulkan 렌더 60fps
- 그리드 + 축 표시 (선택축 하이라이트)

### 검증 기준
- [ ] X+R+스크롤 → X축 회전
- [ ] X+M+스크롤 → X축 이동
- [ ] Y/Z 동일
- [ ] S → 화면 회전, T → 줌
- [ ] 왼쪽 더블클릭 → 객체 선택
- [ ] 우클릭 → 선 삭제
- [ ] UI 축/동작/객체 표시
- [ ] 60fps
