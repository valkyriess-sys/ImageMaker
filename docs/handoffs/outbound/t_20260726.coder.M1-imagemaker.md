## 프로젝트 개요
**이미지메이커 (ImageMaker)**: 손으로 그린 2D 스트로크 → 기하학적 프리미티브 3D 메시 생성 →
스케치한 프로파일을 표면에 투영해 조각(sculpt)하는 도구. 최종 출력은 게임엔진 호환 glTF 2.0.

전체 spec: `docs/spec-v1.md`

---

## M1 범위 (이번 작업)

### Phase 0: 환경 부트스트랩 (가장 먼저)
1. Vulkan SDK 설치 확인 (`vulkaninfo` 실행)
2. vcpkg 초기화 + `glm`, `opencv` 설치
3. CMake 프로젝트 셋업
4. **hello-triangle**: AMD W9700 (RDNA 3) + Linux에서 Vulkan 최소 삼각형 1개 렌더 확인
   - 안 되면 멈추고 리포트 (코드 짜기 전 검증)
5. 성공 시 본작업 진행

### Phase 1: 프리미티브 스케치 생성
1. 입력 추상화: `PointerInput` (마우스 클릭드래그 + 타블렛 펜 압력 → `Stroke.thickness`)
2. 스트로크 전처리 (노이즈 제거, 재표본화)
3. 형태 분류:
   - 닫힌 곡선 + 면적/둘레 비율 → SPHERE (장축/단축 차이 크면 ELLIPSOID)
   - 4꼭지점 근사 → BOX
   - 직선 → CYLINDER
   - 3꼭지점 → CONE
   - 자유곡선(두께) → TUBE
4. 파라미터 추출: 경계박스 → 지름/길이/높이
5. 메시 생성: ICO sphere (subdiv 3, ~1.2k 버텍스), Box, Cylinder, Cone, Tube
6. 정적 Vulkan 뷰어: 생성 메시 렌더 (회전 없음, 고정 카메라, 라이팅 OK)
7. 두께: 비례 고정값 (경계박스 너비 10%) + UI 슬라이더 수정

### 기술 스택
- C++20, Vulkan, glm, OpenCV (형태인식), CMake + vcpkg
- OS: Linux, GPU: AMD Radeon PRO W9700 (RDNA 3, 32GB)
