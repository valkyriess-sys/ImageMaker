## 변경 사항: 8색 순환 → Adobe-style 팔레트

### 이전 (M5 v1)
- `C`키: 8색 프리셋 순환 (blue→red→green→yellow→orange→purple→white→dark)
- 순차적, 반복 누름 필요

### 현재 (M5 v2)
- `C`키: 화면 좌상단에 컬러 팔레트 오버레이 토글
- **8열 × 4행 = 32색** Adobe-style 그리드
- 행 구조:
  - Row 0: Red → Orange (tint gradient)
  - Row 1: Yellow → Green
  - Row 2: Cyan → Blue
  - Row 3: Purple → Magenta
- 팔레트 클릭 → 해당 색상 즉시 객체에 적용 + 팔레트 자동 닫힘
- glTF export: meshColor → baseColorFactor 유지

### 구현
- `buildPalette()`: NDC screen-space quad geometry (GPU vertex/index buffers)
- `tryPickPalette()`: 마우스 클릭 좌표 → 셀 계산 → `adobeColors(row, col)`
- grid pipeline 재사용 (per-vertex color, identity model matrix)
- 팔레트 열려 있을 때 왼쪽 드래그/스컬프트 차단
