## M3 완료 내용

### 스케치 스컬프트 (Phase 3 핵심)
- **레이-메시 교차**: Möller-Trumbore 알고리즘, CPU-side meshIndices 활용
- **screenToRay()**: inverse viewProj → 화면좌표→월드 레이 변환
- **sculptDisplace()**: hit point 근방 모든 vertex에 normal 방향 디스플레이스먼트 적용
  - 부드러운 falloff: `falloff = (1 - d/(strength*2))^2`
- **ADD/SUB 브러시**: `U`키 토글 (brushThickness sign 반전)
- **Undo bake**: `B`키 → 현재 mesh 상태를 baseVertices로 저장
- **자동 sculpt**: 왼쪽 드래그 시 실시간 3D hit 수집 → mouse release 시 한 번에 적용
- **Dynamic VBO**: sculpt 후 즉시 GPU 버퍼 재생성
